# Skills
Skills for AI Usage

## Verfügbare Skills

### MoinRetro
*dein Norddeutscher AI-Buddy für bessere Retros.*

Entwickelt von **Heinz-Sebastian Schiller**.

Hilft dabei, aus einem Thema/Motto oder einer konkreten Teamherausforderung eine
vollständige, methodisch saubere Team-Retrospektive zu entwickeln – inklusive
PowerPoint, separaten Bildern und einer Miro-/Markdown-Version.

➡️ [moinretro/SKILL.md](moinretro/SKILL.md)

#### Nutzung in OpenCode

Repo in das lokale Skill-Verzeichnis klonen bzw. verlinken, z.B.:

```bash
git clone https://github.com/SebastianSchiller/Skills.git ~/.opencode/skill/moinretro-repo
ln -s ~/.opencode/skill/moinretro-repo/moinretro ~/.opencode/skill/moinretro
```

Danach steht der Skill `MoinRetro` in OpenCode zur Verfügung.
